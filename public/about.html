Technical Architecture & Stack

Built with modern web standards and high-performance libraries.

Core Framework

Next.js 16 (App Router)

Server and client components, dynamic routing, and fast SSR page rendering.

UI & Rendering

React 19 & Tailwind CSS v4

State management via StreakContext, glassmorphism tokens, and Lucide React icons.

Backend & Database

Supabase SSR & Client

Authentication, persistent user profiles, daily check-in logs, and habit definitions in Postgres database.

Mobile & PWA

Service Worker & Web Manifest

PWA manifest with offline caching strategy via public/sw.js for native app feel.
